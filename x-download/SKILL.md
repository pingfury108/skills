# LJG-X-Download — X/Twitter 媒体下载

下载 Twitter/X 上的图片和视频。

## 使用方法

1. **获取推文链接**
   - 点击推文右上角分享
   - 复制链接

2. **使用工具下载**
   - 命令行工具：`yt-dlp`
   - 或者在线工具

3. **命令示例**

```bash
# 安装 yt-dlp
pip install yt-dlp

# 下载推文媒体
yt-dlp "https://x.com/username/status/1234567890"
```

## 支持的媒体

- 图片（单张/多张）
- 视频（最高画质）
- GIF
