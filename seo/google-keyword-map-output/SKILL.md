# 关键词地图输出

## 做什么

把研究成果做成一张可执行表格，字段：

```
关键词 | 意图 | 用户想要什么 | 商业价值 | 竞争难度 | 优先级 | 建议页面 | 建议标题
```

按主题分组，每组附：建议页面标题、H1、内容大纲。

## 合格标准

- 团队/自己能**直接照着做内容**，无需二次解读
- 搜索量/竞争度不确定的字段标注"需用工具验证"
- 有明确的「优先做的前 10 个关键词」清单和理由

## 常见坑

- **只列词，不安排页面**——没有页面归属的词表等于没做
- 编造搜索量数字填满表格——虚假精确比空缺更危险
- 表格做完不执行：关键词地图是作战计划，要按 P0 → P1 顺序落地
- 做完不更新：每季度对照 GSC 查询报告回看一次，词库要迭代

## 落地节奏

```
第 1 批：P0 词的页面（本周）
第 2 批：P1 词的页面（2-4 周）
持续：P2 信息型内容（博客更新）
回看：每月 GSC 查询报告 → 新机会词补充进地图
```
