# 耐心迭代

## 做什么

1. 持续更新内容：保持站点有规律的更新频率。
2. 周期性修复：按 GSC 报告每周修一类问题。
3. 观察抓取节奏：GSC 抓取统计信息里看 Googlebot 来访频率变化。

## 合格标准

- 以**数天到数周**为预期单位，而非小时。
- 新站/新子域名：2–4 周起步收录是正常节奏。
- 每次只改一类变量，能归因效果。

## 常见坑

- **今天提交，明天就期待收录**——焦虑驱动的频繁改动反而干扰判断。
- 等不及就乱改：换 URL、改标题、删了重发，每次都重置 Google 的评估周期。
- 频繁请求索引配额刷同一页面，无效果（→ google-request-indexing）。
- 3 天没收录就判定"被惩罚"，实际是正常排队。

## 迭代节奏建议

```
第 1 周：走完 P0 + P1 技术检查，提交 sitemap + 请求索引
第 2–4 周：补内链 + 更新内容，观察 GSC 页面索引报告
第 4 周起：仍不收录 → 回到 google-gsc-monitoring 按原因路由，重点查内容与外链
```
