# 内链发现

## 做什么

1. 找出站内**已被索引**且被抓取频繁的页面（首页、栏目页、热门文章）。
2. 在这些页面正文/导航中加入 `<a href="新页面URL">描述性锚文本</a>`。
3. 确认目标页也在相关页面有入口，形成主题簇互链。

## 合格标准

- 每个重要页面至少有 2–3 个站内入口链接。
- 链接是标准 `<a href>`，渲染前 HTML 源码中可见（或 SSR/预渲染后可见）。
- Google 能顺着链接爬到新 URL（GSC 网址检查 → 引荐页面可验证）。

## 常见坑

- **用 `onclick` / JS 跳转代替 `<a href>`**——爬虫不执行点击，抓不到。
- 链接只在纯客户端渲染（CSR）的组件里，源码中不存在，首抓看不到。
- 只从 sitemap 指望发现，站内零内链——"已发现未编入索引"的典型成因。
- 入口全在页脚"友情链接"区，权重和抓取优先级低。

## 验证

```bash
# 检查源码中是否有真实链接
curl -s https://example.com/source-page | grep -o 'href="[^"]*new-page[^"]*"'
```
